# Paolo Espion — Portfolio

Personal portfolio for Paolo Espion, Computer Science graduate and aspiring software/AI engineer.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `lib/site.ts` to update:

- Email, GitHub, and LinkedIn URLs
- University, graduation year, coursework, and achievements
- Skills
- Project links (`githubUrl`, `liveUrl`)
- Certifications
- GitHub repositories

Replace `public/resume.pdf` with your real resume. Keep the filename so `/resume.pdf` continues to work.
